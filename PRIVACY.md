# Potluck Beta Privacy Notice

Last updated: September 3, 2026

Potluck is currently a small private beta.

## Data stored

Potluck stores only data required for the product to work:

- email address (through Supabase Auth)
- display name and optional handle
- interface language preference
- spaces you create or join
- entries you write
- replies you write
- timestamps
- reply notifications

Potluck does not intentionally collect:
- precise location
- address book / contacts
- advertising identifiers
- payment information
- behavioral advertising data

## Who can see entries

Entries and replies are intended to be visible only to authenticated members of the same Potluck space. Database Row Level Security enforces this membership rule.

## Service provider

The beta uses Supabase for authentication and database hosting and Vercel for web hosting.

## Deletion

The beta does not yet include self-service account deletion in the interface. Before opening Potluck beyond a small invited beta, account/data deletion must be added.

For the current friend beta, the project owner should manually honor deletion requests through the Supabase dashboard.

## Important

This is a product prototype privacy notice, not a substitute for legal review if Potluck is released publicly or commercially.
